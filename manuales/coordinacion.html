4. Quejas

4.1 Contra profesores y sobre cursos

Las quejas vienen de dos lados, y arriba elegís cuáles ver:

Cada tarjeta muestra el profesor (o el curso), la última queja y cuántas tiene.

4.2 Estados de una queja

  1. Pendiente: recién cargada, espera tu decisión.
  2. Aceptada (o Rechazada, si decidís no darle curso).
  3. Revisada: se investigó y quedó una conclusión por escrito.
  4. Resuelta: se aplicó una solución y quedó documentada.

Las quejas de cada profesor están agrupadas por especialidad y, dentro de cada una, por estado.

4.3 Aceptar o rechazar una queja pendiente

Si la rechazás, aparece el campo Motivo del rechazo. Es obligatorio: el botón Confirmar rechazo se habilita recién cuando lo completás.

4.4 Revisar una queja aceptada

Cuando terminás de investigar una queja aceptada, tocá Revisar queja y escribí la Conclusión de la revisión: qué se verificó y a qué se llegó.

Al tocar Completar revisión se registran la fecha y quién la revisó, y la queja pasa a Revisada.

En una queja revisada, tocá Registrar solución y completá los tres campos:

Al tocar Marcar como resuelta, la queja pasa a Resuelta y queda disponible el reporte de solución en PDF:

Una queja Resuelta o Rechazada no se puede reabrir desde esta pantalla. Si hace falta revisar algo de nuevo, coordinalo con Administración para que carguen una queja nueva.

5. Reportes conductuales

Acá administrás el catálogo de códigos que los profesores usan para registrar el comportamiento de los alumnos al tomar asistencia (los códigos N).

5.1 Crear un código

  1. Completá el Código y la Descripción.
  2. Tocá Agregar código.

5.2 Desactivar un código

Tocá Desactivar junto al código y confirmá. Deja de estar disponible para clases nuevas, pero los registros ya cargados con ese código no se borran.
